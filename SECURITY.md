# Security

- **Do not** put exchange API keys in this repository, in issues, or in the dashboard.
- **Do not** enable withdrawals on any key you ever create for a future dedicated binary.
- This default build **cannot** place live orders. `LIVE_TRADING_HARD_DISABLED` is `true`.
- Report vulnerabilities privately. Do not file public issues that include secrets or account identifiers.

If you forked this and added keys: rotate them, assume they leaked, and delete the commit history that contained them.
